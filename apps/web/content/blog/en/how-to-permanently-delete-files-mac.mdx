macOS is designed so that deleting is reversible: files go to the Trash first. When you really want something gone right now, these are the shortcuts and methods that skip that safety net.

## The shortcuts at a glance

| Action | Shortcut | Reversible? |
|---|---|---|
| Move to Trash | <Kbd>⌘</Kbd> <Kbd>⌫</Kbd> | Yes — Put Back from the Trash |
| Delete immediately (skip the Trash) | <Kbd>⌥</Kbd> <Kbd>⌘</Kbd> <Kbd>⌫</Kbd> | No |
| Empty the Trash | <Kbd>⇧</Kbd> <Kbd>⌘</Kbd> <Kbd>⌫</Kbd> | No |
| Empty the Trash without confirmation | <Kbd>⌥</Kbd> <Kbd>⇧</Kbd> <Kbd>⌘</Kbd> <Kbd>⌫</Kbd> | No |
| Undo a Move to Trash | <Kbd>⌘</Kbd> <Kbd>Z</Kbd> | Yes, right after deleting |

On a MacBook keyboard, the key labelled **delete** is the ⌫ key. These shortcuts work in Finder, including on the Desktop.

## Method 1: Option-Command-Delete

1. Select the file or folder in Finder.
2. Press <Kbd>⌥</Kbd> <Kbd>⌘</Kbd> <Kbd>⌫</Kbd>.
3. Click **Delete** in the confirmation dialog.

The item is removed straight away and never appears in the Trash.

## Method 2: Hold Option in the File menu

Select the item, open Finder’s **File** menu and hold <Kbd>⌥</Kbd>: “Move to Trash” changes to **Delete Immediately…**. This is the same action as the shortcut, handy if you forget the keys.

## Method 3: Delete from inside the Trash

Open the Trash, select one or more items and choose **Delete Immediately** from the right-click menu. Useful when you want to keep the rest of the Trash for now.

## Method 4: Empty the Trash

Press <Kbd>⇧</Kbd> <Kbd>⌘</Kbd> <Kbd>⌫</Kbd> in Finder, or right-click the Trash in the Dock and choose **Empty Trash**. Add <Kbd>⌥</Kbd> to skip the “Are you sure?” prompt. More options are in our [empty Trash guide](/blog/empty-trash-mac-shortcut).

## Method 5: Terminal (advanced)

`rm` deletes files permanently with no Trash and no confirmation:

```bash
rm ~/Downloads/old-installer.dmg
```

Be extremely careful — a typo in a path can delete the wrong thing, and `rm -r` deletes whole folders. For everyday use, Finder is safer.

## Method 6: Turn on automatic emptying

If your goal is simply that deleted files don’t pile up, let macOS empty the Trash for you: open Finder → **Settings** → **Advanced** and tick **Remove items from the Trash after 30 days**. Each item is removed 30 days after you trashed it, so you keep a safety window.

## When permanent deletion makes sense

- Large files you are sure you don’t need (old disk images, installers, video exports) when you need the space immediately.
- Sensitive files you don’t want sitting in the Trash.
- Freeing space when the disk is so full that macOS can’t function well.

## When you shouldn’t skip the Trash

- When cleaning up in bulk — one wrong selection is unrecoverable.
- For anything inside `~/Library`, app support folders or system locations.
- When you aren’t sure whether another app still needs the file.

This is exactly why MacDiskCleaner never deletes immediately: everything it cleans goes to the Trash first, so you can put it back if you change your mind.

## What about secure deletion?

Older versions of macOS had **Secure Empty Trash**. Apple removed it in OS X El Capitan because overwriting files isn’t reliable on SSDs. On today’s Macs, **FileVault** encryption (System Settings → Privacy & Security → FileVault) is what makes deleted data practically unrecoverable.
