Deleting a file on Mac normally moves it to Trash first — a safety net that gives you time to change your mind. Sometimes you want to skip that step entirely. Here's how, and when it's actually a good idea.

## The shortcut

Select the file(s) and press:

**Option + Cmd + Delete**

This deletes the selected files immediately, without moving them to Trash first. There's no confirmation dialog by default, so double-check your selection before pressing it.

## Permanently emptying the Trash

If files are already in Trash and you want to force-remove them (including anything that's normally protected from a regular empty):

1. Open Trash from the Dock.
2. Press **Cmd+Shift+Option+Delete** to empty it without the confirmation prompt.

## When you should use permanent deletion

- Files containing sensitive personal information you don't want recoverable
- Freeing space on a nearly-full drive where you need the space back immediately
- Clearing out large files you're certain you'll never need again

## When you shouldn't

For routine cleanup — junk files, old downloads, duplicates — there's no real benefit to skipping Trash, and it removes your safety net. This is exactly why tools like [MacDiskCleaner](/free-mac-cleaner) default to moving everything to Trash first: you get the space back either way once you empty it, but you keep a window to recover a mistake.

## Note on true secure erasure

Modern Macs with SSDs and FileVault encryption make "secure delete" in the old sense (repeatedly overwriting the data) largely unnecessary — the file system's own wear-leveling and encryption already make recovering a deleted file impractical. Option+Cmd+Delete followed by emptying Trash is sufficient for virtually all personal use cases.
