On a Mac, your desktop is just a folder (`~/Desktop`). Anything on it is a real file — so “removing” it can mean very different things. Here is how to get files off the desktop **without deleting them**, from the quickest to the tidiest.

## The one thing that deletes

Only **Move to Trash** (<Kbd>⌘</Kbd> <Kbd>⌫</Kbd>, or dragging to the Trash) deletes a file — and even then it stays recoverable until you empty the Trash. Every method below keeps your files.

## Method 1: Move files into a folder

1. Open a Finder window (<Kbd>⌘</Kbd> <Kbd>N</Kbd>) and pick a destination in the sidebar, such as **Documents**.
2. Select the files on your desktop (drag a box around them or <Kbd>⌘</Kbd>-click each one).
3. Drag them onto the destination folder.

Dragging between folders on the same disk **moves** files; it doesn’t copy or delete them. You can also copy with <Kbd>⌘</Kbd> <Kbd>C</Kbd> and then press <Kbd>⌥</Kbd> <Kbd>⌘</Kbd> <Kbd>V</Kbd> in the destination to move them there.

**To remove a folder from the desktop**, do the same: drag the whole folder into Documents. Its contents go with it.

## Method 2: Group everything with Stacks

Right-click an empty spot on the desktop and choose **Use Stacks** (or press <Kbd>⌃</Kbd> <Kbd>⌘</Kbd> <Kbd>0</Kbd>). macOS groups files by kind — images, PDFs, screenshots — into neat piles you can click to expand. Nothing moves or gets deleted; turn Stacks off the same way.

## Method 3: Hide all desktop icons (files stay put)

On **macOS Sonoma or later**:

1. Open **System Settings → Desktop & Dock**.
2. Under **Desktop & Stage Manager**, turn off **Show Items: On Desktop**.

Your desktop is now clean, but every file is still in the Desktop folder in Finder’s sidebar. Turn the switch back on any time.

While you’re there, set **Click wallpaper to reveal desktop** to **Only in Stage Manager** if your windows keep disappearing when you click the desktop.

On older macOS versions you can hide desktop icons from Terminal (and undo by repeating with `true`):

```bash
defaults write com.apple.finder CreateDesktop false
killall Finder
```

## Method 4: Stop screenshots landing on the desktop

Screenshots are the most common source of desktop clutter. Press <Kbd>⇧</Kbd> <Kbd>⌘</Kbd> <Kbd>5</Kbd>, click **Options**, and under **Save to** choose **Documents** or **Other Location…** (for example a new “Screenshots” folder). Existing screenshots can be moved there with Method 1.

## Method 5: Remove aliases, not originals

Icons with a small curved **arrow** are aliases — shortcuts to a file stored somewhere else. Deleting an alias does **not** delete the original, so it’s safe to trash aliases you no longer use. If you’re unsure, select the icon and press <Kbd>⌘</Kbd> <Kbd>R</Kbd> (Show Original) to see where the real file lives.

## Method 6: Offload to iCloud or an external drive

- **External drive or USB stick:** drag files onto the drive in Finder. This *copies* them; once the copy finishes, you can move the originals to the Trash if you want the space back.
- **iCloud Drive:** with **Desktop & Documents Folders** turned on (System Settings → your name → iCloud → iCloud Drive), desktop files are stored in iCloud and can be offloaded locally when space is low. Be aware that deleting a desktop file then deletes it from iCloud on every device.

## What about the “home screen” on a MacBook?

Many people call the Mac desktop the “home screen”. Everything above applies: screenshots, downloads and folders you see there live in `~/Desktop`. Downloads only appear on the desktop if a browser was set to save there — change that in the browser’s settings (in Safari: **Settings → General → File download location**).

## Freeing space, not just tidying

Moving files around doesn’t free disk space. If the reason you’re clearing the desktop is a “disk almost full” warning, look for what’s actually big: old installers, videos, duplicates and caches. A free [MacDiskCleaner](/free-mac-cleaner) scan lists them with sizes, and anything you remove goes to the Trash first.
