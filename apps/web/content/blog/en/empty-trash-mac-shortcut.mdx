Moving a file to the Trash doesn’t free any space — the file is still on your disk until the Trash is emptied. Here’s every way to do it, plus fixes when it won’t cooperate.

## Empty Trash shortcuts

| What you want | How |
|---|---|
| Empty the Trash | <Kbd>⇧</Kbd> <Kbd>⌘</Kbd> <Kbd>⌫</Kbd> in Finder, then confirm |
| Empty without the “Are you sure?” prompt | <Kbd>⌥</Kbd> <Kbd>⇧</Kbd> <Kbd>⌘</Kbd> <Kbd>⌫</Kbd> |
| Empty from the Dock | Right-click (or Control-click) the Trash → **Empty Trash** |
| Delete just one item | Open the Trash, right-click the item → **Delete Immediately** |
| Restore an item | Open the Trash, select it → **File → Put Back** |

The shortcuts only work when **Finder** is the active app — click the desktop first if another app is in front.

## Empty the Trash automatically

**Option 1 — Finder setting:** Finder → **Settings** → **Advanced** → tick **Remove items from the Trash after 30 days**.

**Option 2 — Storage settings:** System Settings → **General → Storage** → turn on **Empty Trash Automatically**.

Both do the same thing: each item is permanently removed 30 days after you trashed it, so you still have a month to change your mind.

## How much space is in the Trash?

Open the Trash, press <Kbd>⌘</Kbd> <Kbd>A</Kbd> to select everything, then <Kbd>⌃</Kbd> <Kbd>⌘</Kbd> <Kbd>I</Kbd> to see the total size in one window. **System Settings → General → Storage** also shows it. If you’ve been cleaning up, the Trash can easily hold several gigabytes.

## When the Trash won’t empty

1. **Hold Option** while emptying — this bypasses locked-file warnings.
2. **Unlock items:** select the item in the Trash, press <Kbd>⌘</Kbd> <Kbd>I</Kbd> and untick **Locked**.
3. **Quit apps** that may still use a trashed file (the error says “in use”).
4. **Reconnect external drives:** files deleted from a USB drive sit in that drive’s own hidden Trash, so they only disappear when you empty the Trash with the drive connected.
5. **Restart** and try again.
6. **Run First Aid** in Disk Utility on your startup disk if errors persist.

For stubborn files, see [how to force delete files that won’t delete](/blog/how-to-delete-files-mac-wont-delete).

## Empty Trash vs. Delete Immediately

- **Empty Trash** permanently deletes everything currently in the Trash.
- **Delete Immediately** (<Kbd>⌥</Kbd> <Kbd>⌘</Kbd> <Kbd>⌫</Kbd> on a selected file) skips the Trash for that one item.

Both are permanent. If you’re removing lots of files during a clean-up, keeping them in the Trash for a while is the safer habit — that’s why MacDiskCleaner always moves files to the Trash and lets you empty it when you’re ready.

## iCloud Drive files

Files you delete from iCloud Drive are also kept in **Recently Deleted** on iCloud.com for 30 days, and that space still counts against your iCloud storage until it’s cleared there.
