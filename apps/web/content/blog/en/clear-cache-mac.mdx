A cache is a set of files an app keeps so it doesn’t have to download or recalculate the same thing twice. Caches are useful, but they grow, they can get corrupted, and they count towards the “System Data” and “Other” parts of your storage. Here’s how to clear them safely.

## Where Mac caches are stored

| Cache | Location | Safe to clear? |
|---|---|---|
| Your apps’ caches | `~/Library/Caches` | Yes — quit the app first |
| Browser caches | Inside each browser (see below) | Yes |
| System-wide app caches | `/Library/Caches` | Mostly — requires admin; be selective |
| macOS system caches | `/System/Library/Caches` | No — protected and managed by macOS |
| Developer caches (Xcode, npm, Gradle…) | `~/Library/Developer`, `~/.npm`, `~/.gradle` | Yes — tools rebuild them |

The `~` means your home folder. `~/Library` is hidden by default; use **Go → Go to Folder…** (<Kbd>⇧</Kbd> <Kbd>⌘</Kbd> <Kbd>G</Kbd>) in Finder to open it.

## Clear app caches

1. Quit the app whose cache you want to clear.
2. In Finder press <Kbd>⇧</Kbd> <Kbd>⌘</Kbd> <Kbd>G</Kbd>, type `~/Library/Caches` and press Return.
3. Switch to list view and turn on **View → Show View Options → Calculate all sizes** to see which folders are biggest.
4. Move the folders for that app (named like `com.spotify.client`) to the Trash.
5. Open the app again, then empty the Trash once everything works.

Tip: move the folder **contents**, not `~/Library/Caches` itself.

## Clear your browser cache

- **Safari:** Safari → **Settings → Advanced** → tick **Show features for web developers**. Then **Develop → Empty Caches** (<Kbd>⌥</Kbd> <Kbd>⌘</Kbd> <Kbd>E</Kbd>). To clear history and cookies as well, use **History → Clear History**.
- **Chrome:** press <Kbd>⇧</Kbd> <Kbd>⌘</Kbd> <Kbd>⌫</Kbd> to open **Delete browsing data**, choose a time range and tick **Cached images and files**.
- **Firefox:** **Settings → Privacy & Security → Cookies and Site Data → Clear Data…** and tick **Cached Web Content**.
- **Edge:** **Settings → Privacy, search, and services → Clear browsing data → Choose what to clear**.

Clearing only the cache keeps you signed in; clearing cookies signs you out of websites.

## Flush the DNS cache

If websites don’t load after a network change, flushing DNS often fixes it:

```bash
sudo dscacheutil -flushcache; sudo killall -HUP mDNSResponder
```

This doesn’t free disk space — it only resets the list of website addresses your Mac remembers.

## Developer caches

Xcode’s DerivedData, simulator files, and package-manager caches (npm, Yarn, CocoaPods, Gradle, Cargo) are often the largest caches on a developer’s Mac. They are safe to delete because your tools rebuild them — see [MacDiskCleaner for developers](/developers) for what each one is and how it comes back.

## What clearing cache won’t fix

- **A Mac that’s slow because memory is full** — check Activity Monitor instead.
- **A disk that’s full of large files** — caches are rarely the biggest culprit; duplicates, videos, old backups and System Data usually are.
- **Long-term speed** — caches grow back as soon as you use your apps.
