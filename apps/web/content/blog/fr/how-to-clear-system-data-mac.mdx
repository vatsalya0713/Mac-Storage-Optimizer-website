« Données système » (« Autres » sur les anciennes versions de macOS) est la catégorie fourre-tout du stockage de votre Mac. Quelques dizaines de Go, c’est normal. Quand elle atteint **100 Go ou plus**, quelque chose de précis en est presque toujours responsable. Ce guide montre comment le trouver. Pour la procédure complète pas à pas, voyez [comment supprimer les Données système](/clear-system-data-mac).

## D’abord : obtenir un chiffre fiable

Ouvrez **Réglages Système → Général → Stockage** et laissez le calcul se terminer : le premier chiffre est souvent trop élevé. Redémarrez ensuite et vérifiez à nouveau : le redémarrage efface swap et fichiers temporaires et laisse macOS purger les instantanés devenus inutiles.

## Cause 1 : les instantanés locaux Time Machine

Si Time Machine est actif, macOS crée chaque heure des **instantanés locaux** sur le disque interne, surtout quand le disque de sauvegarde n’est pas branché. Ils comptent dans les Données système.

```bash
tmutil listlocalsnapshots /
```

S’il y en a beaucoup, branchez le disque de sauvegarde et laissez une sauvegarde se terminer, ou supprimez les anciens par date :

```bash
sudo tmutil deletelocalsnapshots 2026-09-15-101500
```

macOS les supprime automatiquement quand il manque de place, mais la barre de Stockage ne le reflète pas toujours tout de suite.

## Cause 2 : les vieilles sauvegardes d’iPhone et d’iPad

Chaque sauvegarde locale d’un appareil peut peser **des dizaines de Go**, et les anciennes ne sont jamais supprimées automatiquement. Regardez dans :

`~/Library/Application Support/MobileSync/Backup`

Ou branchez l’appareil, sélectionnez-le dans la barre latérale du Finder et cliquez sur **Gérer les sauvegardes** pour supprimer les anciennes.

## Cause 3 : Xcode, simulateurs et outils de développement

Si vous avez déjà installé Xcode, vérifiez `~/Library/Developer`. DerivedData, les fichiers DeviceSupport iOS et les anciens runtimes de simulateur atteignent facilement 50 Go ou plus.

```bash
du -sh ~/Library/Developer/* 2>/dev/null
xcrun simctl delete unavailable
```

Notre [page développeurs](/developers) explique quels dossiers on peut supprimer.

## Cause 4 : Docker, machines virtuelles et émulateurs

Docker Desktop stocke conteneurs et images dans un seul fichier image disque qui grossit mais rétrécit rarement ; UTM, Parallels et VMware stockent des machines virtuelles entières sous forme de fichiers. Vérifiez leur taille dans les réglages de chaque app, et récupérez l’espace de Docker avec :

```bash
docker system prune
```

(Lisez ce qui sera supprimé avant de confirmer : les conteneurs arrêtés et les images inutilisées.)

## Cause 5 : caches et journaux

Navigateurs, apps de streaming, outils de création et messageries peuvent chacun garder plusieurs Go dans `~/Library/Caches`. Journaux et rapports de plantage se trouvent dans `~/Library/Logs`. Voyez [comment vider le cache sans risque](/blog/clear-cache-mac).

## Cause 6 : les restes d’apps supprimées

Glisser une app dans la Corbeille laisse ses fichiers de support dans `~/Library/Application Support` et `~/Library/Containers`. Jeux, logiciels de montage vidéo et instruments virtuels peuvent laisser des dossiers énormes.

## Trouver vous-même les plus gros dossiers

Cette commande liste les plus gros dossiers de votre Library, le plus gros en dernier :

```bash
du -sh ~/Library/* 2>/dev/null | sort -h | tail -15
```

Avancez du plus gros au plus petit, mais ne supprimez jamais `Keychains`, `Preferences` ni les conteneurs des apps que vous utilisez encore.

## Ce qu’il ne faut pas faire

- **Ne désactivez pas la Protection de l’intégrité du système** et ne supprimez rien dans `/System` : cela ne réduira pas utilement les Données système et peut endommager macOS.
- **N’effacez pas le disque** pour corriger le chiffre, sauf avec une sauvegarde complète et une vraie raison.
- **Méfiez-vous des « nettoyeurs » qui promettent de supprimer les Données système en un clic** sans montrer ce qu’elles contiennent.

## La méthode rapide

Une analyse MacDiskCleaner détaille les caches utilisateur, journaux, données de développement et restes d’apps qui composent l’essentiel des Données système, avec leur taille, et place votre sélection dans la Corbeille. L’analyse est gratuite : vous voyez où est passé votre espace avant de décider quoi que ce soit.
