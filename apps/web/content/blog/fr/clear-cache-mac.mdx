Un cache est un ensemble de fichiers qu’une app conserve pour ne pas télécharger ou recalculer deux fois la même chose. Utiles, les caches grossissent, peuvent se corrompre et comptent dans les « Données système » de votre stockage. Voici comment les vider sans risque.

## Où le Mac stocke les caches

| Cache | Emplacement | Suppression sûre ? |
|---|---|---|
| Caches de vos apps | `~/Library/Caches` | Oui — quittez l’app d’abord |
| Caches des navigateurs | Dans chaque navigateur (voir ci-dessous) | Oui |
| Caches d’apps pour tout le système | `/Library/Caches` | En grande partie — droits admin, soyez sélectif |
| Caches système de macOS | `/System/Library/Caches` | Non — protégés et gérés par macOS |
| Caches de développement (Xcode, npm, Gradle…) | `~/Library/Developer`, `~/.npm`, `~/.gradle` | Oui — les outils les recréent |

Le `~` désigne votre dossier de départ. `~/Library` est masqué par défaut ; ouvrez-le avec **Aller → Aller au dossier…** (<Kbd>⇧</Kbd> <Kbd>⌘</Kbd> <Kbd>G</Kbd>) dans le Finder.

## Vider le cache des apps

1. Quittez l’app dont vous voulez vider le cache.
2. Dans le Finder, appuyez sur <Kbd>⇧</Kbd> <Kbd>⌘</Kbd> <Kbd>G</Kbd>, saisissez `~/Library/Caches` et appuyez sur Entrée.
3. Passez en présentation par liste et activez **Présentation → Afficher les options de présentation → Calculer toutes les tailles** pour voir les dossiers les plus lourds.
4. Placez dans la Corbeille les dossiers de cette app (noms du type `com.spotify.client`).
5. Rouvrez l’app, puis videz la Corbeille une fois que tout fonctionne.

Astuce : déplacez le **contenu** des dossiers, pas `~/Library/Caches` lui-même.

## Vider le cache du navigateur

- **Safari :** Safari → **Réglages → Avancés** → cochez **Afficher les fonctionnalités pour les développeurs web**. Puis **Développement → Vider les caches** (<Kbd>⌥</Kbd> <Kbd>⌘</Kbd> <Kbd>E</Kbd>). Pour effacer aussi l’historique et les cookies : **Historique → Effacer l’historique**.
- **Chrome :** appuyez sur <Kbd>⇧</Kbd> <Kbd>⌘</Kbd> <Kbd>⌫</Kbd> pour ouvrir **Effacer les données de navigation**, choisissez une période et cochez **Images et fichiers en cache**.
- **Firefox :** **Paramètres → Vie privée et sécurité → Cookies et données de sites → Effacer les données…** et cochez **Contenu web en cache**.
- **Edge :** **Paramètres → Confidentialité, recherche et services → Effacer les données de navigation → Choisir les éléments à effacer**.

Vider uniquement le cache vous laisse connecté ; supprimer les cookies vous déconnecte des sites.

## Vider le cache DNS

Si des sites ne se chargent plus après un changement de réseau, vider le DNS règle souvent le problème :

```bash
sudo dscacheutil -flushcache; sudo killall -HUP mDNSResponder
```

Cela ne libère pas d’espace : cela réinitialise seulement la liste des adresses web mémorisées.

## Caches de développement

DerivedData de Xcode, les fichiers du simulateur et les caches des gestionnaires de paquets (npm, Yarn, CocoaPods, Gradle, Cargo) sont souvent les plus gros caches d’un Mac de développeur. On peut les supprimer car vos outils les recréent — voyez [MacDiskCleaner pour les développeurs](/developers) pour le détail de chacun.

## Ce que vider le cache ne règle pas

- **Un Mac lent faute de mémoire** — consultez le Moniteur d’activité.
- **Un disque plein de gros fichiers** — les caches sont rarement le principal coupable ; ce sont plutôt les doublons, vidéos, vieilles sauvegardes et Données système.
- **La vitesse à long terme** — les caches se reconstituent dès que vous utilisez vos apps.

Il ne touche jamais aux caches système protégés.
