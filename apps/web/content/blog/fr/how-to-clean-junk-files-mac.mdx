Les « fichiers inutiles » d’un Mac ne sont pas un seul dossier. C’est un mélange de données temporaires que les apps et macOS créent et nettoient rarement. Voici où ils se trouvent et comment les supprimer sans rien casser.

## Où se cachent les fichiers inutiles du Mac

| Fichiers inutiles | Emplacement | Suppression sûre ? |
|---|---|---|
| Caches des apps | `~/Library/Caches` | Oui — quittez l’app d’abord |
| Journaux et rapports de plantage | `~/Library/Logs` | Oui |
| Vieux téléchargements et installateurs | `~/Downloads` | Oui, après vérification |
| Sauvegardes d’iPhone/iPad | `~/Library/Application Support/MobileSync/Backup` | Les anciennes, oui |
| Pièces jointes de Mail | `~/Library/Containers/com.apple.mail/Data/Library/Mail Downloads` | Oui — elles restent dans les e-mails |
| Caches de développement | `~/Library/Developer`, `~/.npm`, `~/.gradle` | Oui — les outils les recréent |
| Restes d’apps supprimées | `~/Library/Application Support`, `~/Library/Containers` | Oui, pour les apps que vous n’avez plus |
| La Corbeille | `~/.Trash` | Oui — c’est son rôle |

Téléchargements, sauvegardes d’appareils et caches de développement sont généralement les plus volumineux ; caches et journaux s’accumulent avec le temps.

## Option 1 : nettoyer les fichiers inutiles à la main

### 1. Vider les caches et journaux des apps

Quittez vos apps. Dans le Finder, appuyez sur <Kbd>⇧</Kbd> <Kbd>⌘</Kbd> <Kbd>G</Kbd>, ouvrez `~/Library/Caches` et placez dans la Corbeille les dossiers des apps que vous utilisez beaucoup. Faites de même dans `~/Library/Logs`. Les apps recréent ce dont elles ont besoin.

### 2. Vider le dossier Téléchargements

Triez Téléchargements par taille et supprimez les installateurs (`.dmg`, `.pkg`, `.zip`) d’apps déjà installées, ainsi que les fichiers déjà rangés ailleurs.

### 3. Supprimer les vieilles sauvegardes d’appareils

Branchez votre iPhone ou iPad, sélectionnez-le dans le Finder et cliquez sur **Gérer les sauvegardes** — ou supprimez les anciens dossiers de sauvegarde dans le chemin MobileSync ci-dessus.

### 4. Supprimer les restes d’apps supprimées

Cherchez dans `~/Library/Application Support` et `~/Library/Containers` des dossiers portant le nom d’apps que vous n’avez plus.

### 5. Vider la Corbeille

Appuyez sur <Kbd>⇧</Kbd> <Kbd>⌘</Kbd> <Kbd>⌫</Kbd>. Rien n’est libéré avant.

## Ce qui ressemble à des fichiers inutiles, mais n’en est pas

- **Les fichiers de langue dans les apps** — les supprimer casse la signature de code de l’app sur macOS récent. N’y touchez pas.
- **`/System/Library/Caches`** — protégé et géré par macOS.
- **L’espace purgeable** — macOS le libère seul quand c’est nécessaire.
- **Votre photothèque Photos** — elle peut être énorme, mais ce sont vos photos. Utilisez l’[album Doublons](/blog/duplicate-photos-mac) plutôt que de supprimer la photothèque.

## Est-ce sans risque ?

Oui, si vous restez dans les emplacements ci-dessus et gardez les fichiers dans la Corbeille jusqu’à être sûr que tout fonctionne. Fuyez tout outil qui veut supprimer des fichiers système, « optimiser la mémoire » ou nettoyer tous les jours : macOS s’en charge déjà.

## À quelle fréquence nettoyer ?

Tous les un ou deux mois suffisent pour la plupart. Développeurs et monteurs vidéo devraient vérifier plus souvent : caches de compilation et fichiers de rendu grossissent vite.
